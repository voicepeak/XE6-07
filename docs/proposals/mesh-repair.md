# 提案：增加网格修复功能

## 动机 / 用户故事

3D 输出模型可能存在破面、洞、碎片、非流形等问题，影响渲染、导出和后续使用。需要清理不合法网格，提升模型可用性，为后续 UV、贴图和导出做准备。

## 目标用户

- 生成或上传 3D 模型后遇到网格问题的用户
- 需要可交付网格的后续处理流程

## 现有做法及不足

无。当前没有网格修复能力，有问题的模型无法继续后续流程。

## 本期范围

本期做：

- 修洞：填补网格中的空洞区域
- 去碎片：移除与主体不相连的小型孤立网格片段
- 非流形修复：修复非流形边和顶点
- 基础拓扑整理：归一化法线方向、移除退化面

本期明确不做：

- 不做复杂网格编辑、局部雕刻或拓扑重建
- 不做 UV 展开、贴图或材质处理
- 不做支撑生成、切片或打印

## 验收标准

### 例子 1：修洞

- 现状：模型存在孔洞，渲染异常或后续流程报错。
- 提议后的行为：检测并填补孔洞，模型可正常打开和渲染。
- 验收：修复后模型在渲染器中不出现空洞；三角面闭合完整。

### 例子 2：去碎片

- 现状：模型存在孤立的小型碎片，影响外观和后续处理。
- 提议后的行为：识别并移除不与主体连通的碎片。
- 验收：修复后模型只保留主体结构，碎片被移除。

### 例子 3：非流形修复

- 现状：模型存在非流形边或顶点，导致部分算法失败。
- 提议后的行为：检测并修复非流形结构。
- 验收：修复后模型通过流形检查。

### 例子 4：不影响主体结构

- 现状：修复操作可能改变原模型的外观。
- 提议后的行为：修复仅作用于问题区域，不改变主体几何形状和比例。
- 验收：修复前后模型的主体轮廓和尺寸保持一致。

### 例子 5：修复失败

- 现状：无。
- 提议后的行为：无法自动修复的问题应明确报告，不产生虚假的"修复成功"结论。
- 验收：严重损坏的模型返回修复失败状态，包含可理解的原因说明。
