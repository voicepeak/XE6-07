# 提案：网格可打印审计与问题定位报告

## 动机 / 用户故事

用户可以对当前模型运行可打印审计，了解模型是否适合进入切片，以及失败的具体原因和位置。

## 目标用户

- 上传或生成模型后准备进入打印流程的用户
- 需要定位网格问题的创作者
- 消费审计结果的后续流程（切片、发布审核等）

## 现有做法及不足

无。当前没有可打印审计能力，用户无法在进入切片前判断模型是否就绪。

## 本期范围

本期做：

- 对当前待审模型执行以下检查：水密性、流形、最小壁厚、自相交、法线一致性
- 输出通过、警告或失败的审计结论
- 对每项问题给出问题类型、严重程度、说明和可定位的位置
- 在模型预览能力可用时，将问题区域以高亮方式呈现；预览不可用时，报告仍必须可阅读
- 展示审计进行中、成功、失败和无法执行等状态
- 以普通 MVP 测试模型为基准，审计应在 30 秒内返回结果或明确超时失败

本期明确不做：

- 不自动修复模型
- 不执行切片、生成 G-code 或接入打印机
- 不做发布审核、内容审核或版权审核
- 不承诺复杂工业级几何分析

## 基本概念与信息结构

### 审计报告

- `status`: 通过 / 警告 / 失败
- `issues`: 问题列表

### 审计问题

- `type`: 问题类型（水密性、流形、壁厚、自相交、法线）
- `severity`: 严重程度
- `description`: 问题说明
- `location`: 可定位的位置坐标

## 原型 / 演示

### 演示流程

```
用户打开一个存在薄壁和非流形边的模型
-> 发起可打印审计
-> 报告显示"失败"
-> 列出薄壁和非流形问题
-> 预览高亮对应问题区域
```

## 验收标准

### 例子 1：五类检查全部通过

- 现状：无审计能力。
- 提议后的行为：对一个水密、流形、壁厚足够、无自相交、法线一致的有效模型运行审计。
- 验收：审计结论为"通过"，问题列表为空；审计在 30 秒内完成。

### 例子 2：存在非流形边

- 现状：无。
- 提议后的行为：对存在非流形边的模型运行审计，报告标记为"失败"或"警告"。
- 验收：问题列表包含非流形问题，每项有类型、严重程度、说明和位置坐标。

### 例子 3：预览高亮问题区域

- 现状：无。
- 提议后的行为：当模型预览可用时，审计报告中的问题区域在 3D 视图上高亮显示。
- 验收：用户可看到高亮区域与报告中列出的位置坐标对应。

### 例子 4：预览不可用时报告仍可读

- 现状：无。
- 提议后的行为：当 3D 预览不可用时，审计报告仍以可阅读的方式展示全部问题。
- 验收：报告以文字和坐标形式展示问题，用户无需 3D 预览也能理解问题所在。

### 例子 5：审计超时

- 现状：无。
- 提议后的行为：对异常复杂的模型，审计在 30 秒内未完成时返回超时状态。
- 验收：审计返回"超时"状态，不无限等待；用户可看到明确反馈。

### 例子 6：无法执行

- 现状：无。
- 提议后的行为：对格式错误或无法解析的模型发起审计时，返回"无法执行"状态。
- 验收：返回明确的错误说明，不产生虚假的通过或失败结论。
