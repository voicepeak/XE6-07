# 提案：模型详情、3D 预览与 STL/3MF 下载

## 动机 / 用户故事

用户可以从公共模型库打开一个已公开模型，查看完整信息和 3D 预览，并下载该模型经过审核的 STL 或 3MF 文件。

## 目标用户

- 浏览公共模型库并希望深入了解和下载模型的普通用户
- 需要确认模型外观后再决定下载的用户

## 现有做法及不足

无。当前没有模型详情页、3D 预览或文件下载能力。

## 本期范围

本期做：

- 详情页展示：3D 预览、标题、作者、描述、分类、标签、授权方式及是否允许 Fork、发布时间、收藏数、下载数
- 详情页展示审核通过时绑定的模型版本，不自动切换到未经审核的新版本
- 3D 预览支持基础旋转、缩放和重置视角
- 预览加载中、缺失或失败时显示对应状态，其他信息仍可阅读
- 下载：只展示实际存在且允许公开下载的 STL / 3MF 文件
- 不提供 G-code 下载入口
- 文件缺失或不可用时禁用对应操作并说明原因
- 下载失败给出重试提示，只有成功获得文件才增加下载数
- 下载的文件属于当前审核通过的公开版本
- 公开状态变化：私有/审核中/审核未通过的模型不能通过直接 URL 打开
- 已下架模型显示"该模型已下架"，不再提供预览和下载
- 用户打开页面后模型被下架时，后续下载请求被拒绝
- 错误或不存在的模型地址显示明确的未找到状态

本期明确不做：

- 不做收藏操作和"我的收藏"
- 不做举报和 Fork
- 不做评论、评分、作者主页和关注
- 不做 G-code 下载
- 不做实际打印成功次数和成品图
- 不做复杂文件版本选择

## 关键决策与依据

### 备选方案

1. 详情页仅展示文字信息，不提供 3D 预览
   - 优点：实现简单
   - 缺点：用户无法在下载前确认模型外观
2. 详情页包含 3D 预览和文件下载
   - 优点：完整的浏览到下载闭环
   - 缺点：需要 3D 渲染能力和文件服务

### 本期选择

选择方案 2。原因：3D 预览是用户决定是否下载的关键环节，没有预览的详情页价值有限。

## 基本概念与信息结构

### 模型详情

- `title`: 标题
- `author`: 作者
- `description`: 描述
- `category`: 分类
- `tags`: 标签列表
- `license`: 授权方式
- `allow_fork`: 是否允许 Fork
- `published_at`: 发布时间
- `favorites_count`: 收藏数
- `downloads_count`: 下载数
- `files`: 当前公开版本可下载的 STL / 3MF 文件列表

### 下载计数规则

只有成功获得完整文件的下载请求才增加下载数。下载失败、取消或权限拒绝时不增加。

## 原型 / 演示

### 演示流程

```
用户从公共模型库打开"猫咪钥匙扣"
-> 旋转和缩放 3D 预览
-> 查看作者、描述、分类、标签和授权
-> 下载 STL
-> 下载数增加 1
-> 页面始终没有 G-code 下载入口

管理员下架该模型
-> 用户刷新详情页
-> 页面显示"该模型已下架"
-> STL / 3MF 下载不可用
```

## 验收标准

### 例子 1：正常浏览详情

- 现状：无详情页。
- 提议后的行为：从公共模型卡片进入详情页，展示 3D 预览、作者、描述、分类、标签、授权和发布时间。
- 验收：页面包含所有列出字段；3D 预览可旋转、缩放和重置视角。

### 例子 2：下载 STL

- 现状：无下载功能。
- 提议后的行为：用户从详情页下载 STL 文件，下载成功后计数增加。
- 验收：下载的 STL 文件属于当前公开版本；下载数增加 1；页面不展示 G-code 下载入口。

### 例子 3：下载失败

- 现状：无。
- 提议后的行为：文件服务异常时下载失败，用户看到重试提示。
- 验收：下载数不增加；用户可点击重试。

### 例子 4：文件不可用

- 现状：无。
- 提议后的行为：当前版本没有 STL 或 3MF 文件时，对应下载操作被禁用并说明原因。
- 验收：下载按钮或入口处于禁用状态，附带不可用说明。

### 例子 5：预览失败不影响详情

- 现状：无。
- 提议后的行为：3D 预览加载失败时显示占位状态，其他文字信息（标题、作者、描述等）仍可正常阅读。
- 验收：预览区域显示失败占位，其余内容区域正常渲染。

### 例子 6：非公开模型不可访问

- 现状：无。
- 提议后的行为：私有、审核中、审核未通过的模型不能通过直接 URL 打开详情页。
- 验收：直接访问非公开模型的 URL 返回未找到或不可访问状态。

### 例子 7：已下架模型

- 现状：无。
- 提议后的行为：已下架模型显示"该模型已下架"，不提供预览或下载。
- 验收：页面展示下架提示；预览和下载区域不可用；用户打开页面后模型才被下架时，后续下载请求被拒绝。

### 例子 8：版本控制

- 现状：无。
- 提议后的行为：作者上传新版本但未经审核时，详情页继续展示已审核通过版本的预览和下载。
- 验收：预览和下载的文件来自已审核版本，而非最新上传的未审核版本。
